    💾 Respaldos de la base
    
    
    
    
    
      
      
    
      
    
      
      
    
    
    
    
    
    
    
    
      Cómo restaurar un respaldo
      
      
        
    1. Detenga el hub y frps.
      2. 
        
    2. En la carpeta del proyecto: node api/src/respaldo.js restaurar <archivo> --hub-detenido
      
          Verifica el respaldo, guarda la base actual como hub.db.antes-de-restaurar-… y la reemplaza. Si está cifrado (.enc), defina antes BACKUP_KEY con la misma clave.
      3. 
        
    3. Arranque de nuevo. Todos deberán iniciar sesión otra vez (las sesiones no se respaldan).
      4. 
      
    
    
    
  
    

    



    
  
    
    
    Alertas
    
    
    Aviso cuando una máquina pierde la conexión, cuando vuelve y cuando el servidor frps no responde.
    

    
    
      
      
      
    Evita avisos por micro-cortes. frps tarda hasta 45 s más en notar una máquina que se apagó de golpe.
