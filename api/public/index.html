Actividad

    Registrar máquina

    Se genera un token único y el frpc.toml listo para instalar en el equipo.
    Será el usuario frp y parte de los subdominios.

    Credenciales de la máquina

    ⚠ El token no se vuelve a mostrar. Descargue ahora el instalador; si lo pierde, use "Generar instalador" en el detalle de la máquina.

    Instalar en el equipo

    Dominio o IP pública del VPS; en pruebas, la IP de LAN o ZeroTier del PC donde corre frps.
    Ver frpc.toml
